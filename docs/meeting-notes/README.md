# Meeting Notes

Use this folder for concise records of Microsoft mentor and internal team meetings.

Suggested filename format:

`YYYY-MM-DD-topic.md`

Suggested template:

```md
# Meeting: <title>

Date: YYYY-MM-DD
Attendees: ...

## Key Updates
- ...

## Decisions
- ...

## Open Questions
- ...

## Action Items
- [ ] Owner — task

## Next Meeting
- ...
```

Focus on decisions, requirements, blockers, and action items rather than writing a transcript.
