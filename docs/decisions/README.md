# Architecture Decision Records

Use this folder for short records of major technical decisions that affect multiple workstreams.

Suggested format:

```md
# ADR-00X: Decision Title

## Status
Proposed / Accepted / Superseded

## Context
What problem or decision are we facing?

## Decision
What did the team choose?

## Alternatives Considered
What other approaches were considered?

## Consequences
What tradeoffs, follow-up work, or constraints result from this decision?
```

Examples of decisions worth documenting:

- frontend framework;
- backend framework;
- test/evaluator representation;
- PostgreSQL usage strategy;
- Azure hosting services;
- deployment automation approach;
- authentication and secrets strategy.
